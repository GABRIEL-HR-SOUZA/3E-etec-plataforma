# 3E-etec-plataforma

**Plataforma de Vagas - SECITEC**
Uma plataforma web moderna desenvolvida para conectar alunos da SECITEC a oportunidades de emprego e estágio publicadas por empresas da região.
**📝Sobre o Projeto**

projeto surge com o objetivo de centralizar e facilitar o fluxo de contratação dentro do ecossistema da SECITEC. A plataforma permite dois tipos de perfis: 
Alunos: Podem criar currículos, visualizar vagas disponíveis e se candidatar.Empresários: Podem publicar vagas, gerenciar candidaturas e visualizar perfis de alunos interessados.
🛠️ Tecnologias UtilizadasO projeto utiliza uma stack robusta e de alta performance:Backend: Java Quarkus (Supersônico e Subatômico)
Frontend: TypeScript (Interface dinâmica e tipada)
Banco de Dados: PostgreSQL (Relacional e confiável)
